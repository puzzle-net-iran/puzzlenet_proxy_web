## Что это такое

В Telegram появился новый тип прокси под названием **WEB**. В отличие от классического MTProto-прокси, его трафик выглядит как обычный HTTPS, поэтому он может без проблем работать через Cloudflare.

PuzzleNet Proxy превращает бесплатный Cloudflare Worker именно в такой прокси.

**Простыми словами:** Cloudflare — это огромная всемирная сеть, через которую проходит значительная часть интернет-сайтов, поэтому её полная блокировка обходится цензорам слишком дорого. Ваш Worker — это небольшая программа, работающая внутри этой сети. Telegram связывается с вашим Worker, а Worker пересылает трафик на серверы Telegram.

- **Выглядит как обычный веб-сайт.** Любой человек или робот-цензор, открывший ваш адрес в браузере, увидит обычный интернет-магазин одежды.
- **Не может читать ваши сообщения.** Telegram использует сквозное шифрование между вашим приложением и серверами. Прокси переносит только эти зашифрованные байты.
- **Ничего не стоит в обслуживании.** Worker работает в рамках щедрого бесплатного тарифа Cloudflare. Единственный необязательный расход — покупка собственного домена (обычно несколько долларов в год).

## Перед началом

Вам понадобятся:

1. **Аккаунт Cloudflare.** Это бесплатно. Зарегистрируйтесь на [dash.cloudflare.com](https://dash.cloudflare.com/).
2. **Доменное имя (настоятельно рекомендуется).** Стандартные адреса `workers.dev` заблокированы в ряде стран (например, в Иране) и могут быть ограничены по портам. Подойдёт любой недорогой домен, добавленный в Cloudflare.
3. **Приложение Telegram с поддержкой типа WEB-прокси.** В Telegram Desktop эта поддержка уже включена из коробки. Мобильные клиенты получают её по мере выхода обновлений.

## Настройка — пять шагов

### Шаг 1 — Создайте Worker

1. Откройте [панель Cloudflare](https://dash.cloudflare.com/).
2. Перейдите в раздел **Workers & Pages** → **Create application** → **Create Worker**.
3. Укажите любое имя (например, `puzzlenet-proxy`) и нажмите **Deploy**.

### Шаг 2 — Вставьте код

1. На странице созданного Worker нажмите **Edit code**.
2. Удалите всё содержимое редактора и вставьте полный код из файла [`worker.js`](worker.js).
3. Нажмите **Deploy**.

### Шаг 3 — Задайте ключ администратора (единственная обязательная настройка)

1. Откройте адрес вашего Worker в браузере. Вы увидите **страницу начальной настройки (setup page)**, которая предложит случайный ключ. Скопируйте его.
2. В панели управления откройте ваш Worker → **Settings** → **Variables and Secrets** → **Add**:
   - **Name:** `ADMIN_KEY`
   - **Value:** скопированный ключ (или любой пароль длиной от 16 латинских букв и цифр)
3. Нажмите **Deploy**.

> [!IMPORTANT]
> Относитесь к `ADMIN_KEY` как к паролю. Любой, у кого он есть, сможет открыть вашу панель и узнать секретный ключ прокси.

### Шаг 4 — Подключите собственный домен

1. Добавьте ваш домен в Cloudflare. Сервис предоставит два NS-сервера. Укажите эти серверы в панели регистратора, где был куплен домен.
2. В настройках вашего Worker перейдите в **Settings** → **Domains & Routes** → **Add** → **Custom Domain**.
3. Введите поддомен, например `tg.yourdomain.com`. Cloudflare автоматически выпустит SSL-сертификат и настроит DNS.

### Шаг 5 — Откройте панель и подключитесь

Перейдите по адресу:

```text
https://tg.yourdomain.com/YOUR_ADMIN_KEY
```

Панель предлагает два способа подключения:

- **В один клик:** кнопка **Connect in Telegram** для каждого из шести портов. На телефоне или компьютере с установленным Telegram нажатие сразу активирует прокси.
- **Вручную:** параметры **сервер**, а также пара **порт** и его уникальный **секрет (secret)** для самостоятельного ввода:

| Поле | Значение |
|---|---|
| Сервер (Server) | `tg.yourdomain.com` |
| Порт (Port) | любой из `443` · `2053` · `2083` · `2087` · `2096` · `8443` |
| Секрет (Secret) | секрет, указанный для выбранного порта в таблице панели |

Где указать эти параметры в Telegram:

- **Desktop:** Настройки → Продвинутые настройки → Тип соединения → Использовать свой прокси → Добавить прокси → **WEB**
- **Мобильные:** Настройки → Данные и память → Прокси → Добавить прокси → **WEB** (когда пункт станет доступен в вашей версии)

**Готово.** Чтобы поделиться прокси с близкими, отправьте им **ссылки или параметры подключения (сервер, порт и соответствующий ему секрет)**. Никогда не отправляйте адрес панели администратора.

## Порты

Все шесть защищённых HTTPS-портов Cloudflare работают без дополнительных настроек:

`443` · `2053` · `2083` · `2087` · `2096` · `8443`

Каждый порт имеет свой собственный уникальный секрет (генерируемый детерминированно), чтобы изолировать соединения и предотвратить помехи. Если один из портов блокируется или замедляется, переключитесь на другой порт и используйте соответствующий ему секрет из панели. Вы можете добавить несколько портов в Telegram и переключаться между ними в любой момент.

## Справочник параметров

Обязательным является только `ADMIN_KEY`. Все остальные параметры опциональны.

| Переменная | Назначение |
|---|---|
| `ADMIN_KEY` | **Обязательно.** Пароль к вашей панели. Секретные ключи портов прокси генерируются на его основе. |
| `SECRET` | Фиксированный 32-значный hex-секрет для порта 443 (и основа для остальных портов). Укажите его, если хотите иметь возможность изменять `ADMIN_KEY` позже без сброса ранее розданных ссылок. |
| `EXTRA_HOSTS` | Другие домены, привязанные к этому Worker, через запятую. Панель создаст ссылки и для них. |
| `DECOY_URL` | Настоящий сайт, который будет отображаться посетителям вместо страницы магазина по умолчанию. Это делает прокси ещё менее заметным. |
| `CARRIER` | Оставьте пустым. Задавайте значение `websocket` только если режим по умолчанию работает нестабильно. |

> [!WARNING]
> Если параметр `SECRET` не задан, изменение `ADMIN_KEY` приведёт к смене секретов прокси, и **все ранее розданные ссылки перестанут работать.**

## При жёстких блокировках

Попробуйте следующие шаги по порядку:

1. **Смените порт.** Используйте другой порт из списка выше.
2. **Используйте другой домен.** Если один домен заблокирован, привяжите к тому же Worker второй домен и добавьте его в переменную `EXTRA_HOSTS`.
3. **Используйте чистый IP Cloudflare (только Desktop).** Если IP-адреса, на которые указывает ваш домен, заблокированы ТСПУ или провайдером, перенаправьте домен на работающий IP Cloudflare через файл `hosts`:
   - Windows: `C:\Windows\System32\drivers\etc\hosts`
   - macOS / Linux: `/etc/hosts`

   ```text
   CLEAN_IP   tg.yourdomain.com
   ```

   Замените `CLEAN_IP` на работающий IP-адрес Cloudflare. Чистые IP различаются у разных операторов связи и могут со временем устаревать, поэтому проверяйте их самостоятельно.
4. **Отключите ECH там, где он блокируется (критично для России).** В панели Cloudflare для вашего домена откройте: **SSL/TLS** → **Edge Certificates** → **Encrypted Client Hello (ECH)** → **Off (Выключено)**.

> [!NOTE]
> Ни один прокси не способен работать во время **полной** изоляции интернета (национальный шатдаун / «белые списки»). Серверы Cloudflare находятся за границей, поэтому при отключении трансграничных каналов доступ к ним пропадает. Эти меры защищают при DPI-фильтрации и точечных блокировках, но не при полном физическом отключении внешнего трафика.

## Устранение неполадок

| Что вы видите | Что делать |
|---|---|
| По адресу открывается интернет-магазин | Это нормально. Прокси работает скрытно под ним. Чтобы открыть панель, добавьте `/YOUR_ADMIN_KEY` к адресу. |
| По адресу панели тоже открывается магазин | Ключ в адресе не совпадает с `ADMIN_KEY`, либо вы забыли нажать **Deploy** после добавления переменной. |
| Снова открывается страница начальной настройки | Переменная `ADMIN_KEY` не задана или содержит менее 16 символов. |
| Telegram бесконечно пишет «соединение» (connecting) | Попробуйте другой порт. Затем проверьте другой домен. На стандартном `workers.dev` подключите свой домен. |
| Розданные ссылки перестали подключаться | Был изменён `ADMIN_KEY`, пока `SECRET` не был зафиксирован. Отправьте новые ссылки из панели. |

## Часто задаваемые вопросы (FAQ)

<details>
<summary><b>Какие клиенты Telegram поддерживаются?</b></summary>
Любое приложение Telegram, в котором доступен тип прокси <b>WEB</b>. В Telegram Desktop он уже работает штатно. В версиях для Android и iOS поддержка появляется по мере выхода обновлений приложений.
</details>

<details>
<summary><b>Сколько человек могут пользоваться одним прокси?</b></summary>
Проект рассчитан на личное использование и небольшой круг друзей. Бесплатный тариф Cloudflare включает 100 000 запросов в день на аккаунт. Для больших групп лучше развернуть отдельные Worker — это распределит нагрузку, и утечка одной ссылки не приведёт к отключению всех пользователей.
</details>

<details>
<summary><b>Могут ли Cloudflare или владелец прокси читать сообщения?</b></summary>
Нет. Telegram защищает трафик сквозным шифрованием MTProto между вашим приложением и серверами мессенджера. Прокси лишь пересылает зашифрованные пакеты и не имеет ключей для их расшифровки.
</details>

<details>
<summary><b>Можно ли добавить канал-спонсор (Ad Tag)?</b></summary>
Нет. Для работы каналов-спонсоров требуется сервер с постоянным исходящим TCP-портом. Cloudflare использует динамическую трансляцию портов (NAT), поэтому работа рекламного тега в среде Workers технически невозможна. Прокси подключается напрямую к серверам Telegram без рекламы.
</details>
